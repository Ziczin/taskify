# Taskify — презентация проекта

Машинная версия: `docs/presentation/taskify.pptx` (15 слайдов).
Макеты экранов: `docs/presentation/today.png`, `achievements.png`, `collection.png`,
схемы: `architecture.png`, `dataflow.png`. Макеты светлые, повторяют новую палитру.

## 1. Что это

Taskify — настольное приложение для повседневных дел, которое считает прогресс
и не отправляет данные в сеть. Задания четырёх видов (привычки, повторы, разовые,
чек-листы), опыт и уровни без потолка, монеты и косметика, ачивки и комбо,
полный журнал событий и контент-паки в TOML.

Реализация — Rust 1.96, четыре крейта, egui/eframe для окна.

## 2. Экраны

- **Сегодня** — карточки заданий «шахматкой» в четыре колонки, поиск и фильтры,
  кнопки «Завершить» и «Отклонить»; свайпов нет.
- **Неделя** — сводка по дням, цель недели и её закрытие.
- **Паки** — установка из zip, состояние паков, отчёт валидатора.
- **Ачивки** — прогресс по каждой ачивке и награда.
- **Коллекция** — темы (светлая и тёмная), акцент, шрифт; бесплатно, за монеты
  или за уровень.
- **История** — журнал событий с фильтрами по типу, датам и тексту.
- **Настройки** — язык, тема, начало дня, норма, цель недели, окно отмены,
  бэкап, пересборка кеша, проверка целостности.

## 3. Архитектура

```
taskify-ui (окно + команды)
        |
    engine            (правила: награды, комбо, ачивки, покупки)
        |
  taskify-store  —  журнал, кеши, replay, бэкапы
  taskify-packs  —  TOML-паки, реестры, валидатор, zip
        |
   taskify-core  —  модель задания, уровни, награды, время
```

Зависимости идут только вниз: `core` не знает ни о хранилище, ни о паках.
Правила игры живут в `engine` и работают поверх хранилища и паков.

## 4. Данные

Действие → событие (`seq`, `id`, `ts`, полный снимок задания) → строка в
`data/log/YYYY-MM.jsonl` (только добавление, `fsync`) → чистая функция
`apply()` обновляет `state.json` и `aggregates.json` (атомарно, tmp → rename).

Журнал не переписывается: отмена — это компенсирующее событие. Кеши можно
удалить, профиль пересоберётся из журнала. Обрыв записи в хвосте лечится
усечением, битая строка в середине — ошибка с файлом и номером строки.
Бэкапы четырёх уровней: 5 минут (час), час (сутки), день (неделя),
неделя (3 месяца). Импорт создаёт новый профиль.

## 5. Паки

Пак — папка `pack.toml` + `tasks/`, `combos/`, `achievements/`, `cosmetics/`,
`definitions/`: один файл — одна сущность. Id получают префикс пака
(`starter/water`), поэтому паки не конфликтуют. Валидатор выдаёт коды
PK001–PK014 и предупреждения W001–W002; установка при этом не блокируется.
Защита от path traversal, лимиты 512 МБ / 20 000 файлов и проверка степени
сжатия. Встроенных паков семь: `starter` (20 заданий, темы и косметика),
`health`, `focus`, `home`, `sport`, `mind`, `money` — всего 65 заданий, 12 комбо
и 25 ачивок, названия на восьми языках.

## 6. Экономика и уровни

- Кривая из четырёх участков, без потолка; эталонный 77 777 уровень стоит
  около 7.8·10¹⁸ опыта, максимум по `u64` — около 85 843 уровней.
- Вехи: каждые N выполнений множитель на опыт и монеты (аддитивные бонусы).
- Комбо: окно день/неделя/месяц, бонус один раз за окно или однократно.
- Ачивки: условия из метрик, вложенные `all_of`/`any_of`, честный прогресс.
- Опыт не тратится, монеты уходят на косметику; штрафов нет.

## 7. Надёжность и скорость

- Старт профиля — 125 мс на холодном кеше и 12 мс на прогретом (цель 700 мс).
- Пересчёт 100 тыс. событий укладывается в секунды; кеш открывается мгновенно.
- Все экраны прошли смоук-тест на панику при запуске.
- 84 теста, `clippy -D warnings` и `fmt --check` — чисто.

## 8. Один файл и команды

```
taskify.exe                       окно приложения (двойной клик)
taskify validate pack <путь>      коды PK, ненулевой выход при ошибках
taskify validate all              все паки профиля
taskify validate history default  сверка кеша с журналом
taskify rebuild|backup|stats|log  обслуживание без окна
taskify import <zip> <имя>        новый профиль
taskify export <профиль> <zip>    архив профиля
```

При запуске двойным кликом собственное окно консоли прячется; при запуске из
терминала вывод остаётся.

## 9. Оформление

Мягкая палитра: почти белый фон, белые карточки, приглушённый акцент; тёмная
тема — холодный серый без чёрного. Скругления: окно 16, карточки 14, кнопки 12.
Темы — часть стартового пака, а не только настройка.

## 10. Как запустить

```powershell
cargo build --release
.\target\release\taskify.exe
```

Данные — в `%APPDATA%\taskify` или в `TASKIFY_HOME`. Первый запуск сам ставит
все встроенные паки и создаёт профиль. Бинарник — GUI-приложение: двойной клик
открывает окно без консоли, из терминала работают команды.

## 11. Ограничения этапа

Редакторов нет — контент правится в TOML. Престиж и сезоны отложены.
Импорт не сливает профили. В интерфейсе один профиль (`default`).
